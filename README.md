# Minipress

Небольшой сервис для публикации статей в Markdown без регистрации.
После создания статьи выдаются две ссылки: публичная для чтения и секретная для редактирования.

Стек: Go, htmx, SQLite.

![Экран редактирования](/assets/edit.png)

## Что умеет

- Редактор с предпросмотром Markdown и автосохранением
- Черновики и публикация. Черновик по публичной ссылке возвращает 404
- Markdown с поддержкой GFM, подсветкой кода и очисткой HTML
- Светлая и тёмная темы

## Запуск

```bash
go run ./cmd/app
```

После запуска сайт доступен по адресу http://localhost:8080.

Тесты запускаются командой:

```bash
go test ./...
```

Настройки задаются через переменные окружения. Примеры есть в `.env.example`: порт, путь к базе данных, папка для изображений и время ночной очистки.

## Редактор и изображения

Для предпросмотра редактор отправляет Markdown на `/preview`. Сервер возвращает готовый HTML, но ничего не сохраняет. Запрос выполняется через 300 мс после ввода.

Сохранение идёт через `/update`: через 1,5 секунды после ввода сервер проверяет изменения и записывает статью в базу, только если текст действительно изменился.

Загруженные изображения перекодируются в JPEG, EXIF удаляется. Большие изображения уменьшаются до 1600 пикселей по большей стороне.

## Ночная очистка

Раз в сутки запускается очистка. По умолчанию она работает в 23:30.

1. Удаление пустых черновиков: статья не опубликована, создана больше часа назад, заголовок и текст пустые.
2. Удаление неиспользуемых картинок.

Чтобы не проверять все статьи каждую ночь, сервис отслеживает изображения при редактировании. После загрузки изображение получает метку `orphaned_at`. При каждом сохранении статьи сервис проверяет, какие изображения остались в тексте, и обновляет метки.

Ночью удаляются файлы, у которых метка стоит больше суток. Это оставляет время вернуть изображение в статью, если его убрали случайно.

Запустить очистку вручную:

```bash
go run ./cmd/app -cleanup-now
```
## Защита от перегрузки

- лимит запросов по IP (создание статьи, предпросмотр и сохранение, загрузка картинок)
- ограничения на размер запросов и картинок
- не больше двух одновременных обработок картинок

Если сервис работает за nginx или Caddy, переменную `TRUST_PROXY` нужно установить в `true`. Иначе запросы будут учитываться по IP прокси, а не реального клиента.

## Структура проекта

```text
cmd/app             запуск приложения
internal/config     конфигурация
internal/database   SQLite и миграции
internal/repository запросы к базе данных
internal/service    Markdown, изображения и токены
internal/worker     фоновая очистка
internal/handlers   HTTP-обработчики
web                 шаблоны и статика
```
